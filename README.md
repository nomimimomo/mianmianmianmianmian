# 鲜虾鱼板面 V8.5

以没有备份清理功能的 V7.6 原版为基础，仅新增备份清理功能、修复 User 世界书的智能回车。原版页面、尺寸定位、悬浮按钮、文风与 C/U 保存逻辑保留。

## 使用

用本包文件替换原扩展目录里的对应文件并刷新页面。无需安装额外后端，也无需 storage.js。

在酒馆扩展设置中的“备份清理”选择保留期限和执行时间，选择后自动保存，无额外保存按钮。同一酒馆账户重新打开时读取已保存设置。

“手动删除”打开聊天备份弹窗，可展开预览、按内容搜索并勾选删除。自动清理处理过期聊天备份及酒馆设置备份。

V8.5 使用 V7.6 原有的文风与 C/U 数据位置。V8.4 新存储位置的内容不会自动迁回，请保留已有 .mian 恢复备份。

具体改动、验证结果和兼容范围见《V8.5更新报告.md》。
