# 鲜虾鱼板面 V8.4

基于 V8.3 保留文风与 C/U 界面，修复独立存储、读取恢复、清理设置跨设备保存和酒馆设置备份清理。无需额外后端。

## 安装

替换原扩展目录内本包的文件，包含新增的 `storage.js`，刷新酒馆页面。不要同时安装多份鱼板面。保留你已找回的 `.mian` 备份。

## 本次更新

- 文风、C、U、User 标签、清理偏好分开提交，取消普通编辑的旧整包写回。
- 清理器不调用文风/C/U 数据加载入口，不初始化旧总数据缓存。
- 酒馆账户记录提交后读取核对；电脑、手机使用同一酒馆账户可读取相同内容与偏好。
- 重新打开时恢复上次 C/U 身份并读取酒馆现有资料；有外部修改时不强行套旧正文。
- 不在读取新对象前清空已保存的恢复记录；拒绝旧对象延迟草稿事件。
- 文风导入对比只保留文风候选，整体 `.mian` 导入后清除旧编辑器运行状态。
- 使用酒馆原生 Data Maid 按保留期限处理聊天与设置备份，保留聊天备份弹窗和内容搜索。
- 不删除当前聊天、当前酒馆设置、当前文风/C/U 草稿。旧酒馆缺少设置备份删除接口时明确提示。
- 保留原版 C/U 和文风布局；补齐世界书重绘后的智能回车，防止重复监听。
- 新增独立笔记页：空白正文、标题、常用编辑工具与自动保存，不绑定角色或世界书。

完整功能和保存行为见 `功能说明.md`；变更、测试和限制见 `更新报告.md`。

## 接口资料

- SillyTavern `public/scripts/util/AccountStorage.js`
- SillyTavern `public/script.js` 的 settingsReady、saveSettings
- SillyTavern `src/endpoints/settings.js`
- SillyTavern `src/endpoints/data-maid.js` 的 report、delete、finalize
- 酒馆助手 `src/function/variables.ts`（核对旧版变量保存行为，普通总数据写回已移除）

以上接口按官方仓库 release/main 源码核对。没有安装或修改用户酒馆后端。
