# 鲜虾鱼板面 V8.3

SillyTavern 第三方界面扩展。V8.3 基于 V7.7 更新，版本号在扩展信息、设置面板、启动日志和诊断日志中一致。

## 安装

1. 从 GitHub 安装时，把压缩包中 `鲜虾鱼板面` 文件夹内的六个文件放到仓库根目录，让 `manifest.json` 和 `index.js` 直接位于仓库首页；手动安装时，将整个文件夹放入当前用户的 SillyTavern 扩展目录 `data/<user-handle>/extensions/`。
2. 启用酒馆助手扩展（TavernHelper），它提供角色、User 和世界书读写接口。
3. 停用旧版鱼板面的酒馆助手脚本，刷新酒馆页面。请勿让两个版本同时运行，以免出现两个面板或覆盖同一份草稿。
4. 从扩展菜单、扩展设置区或悬浮按钮打开。手机找不到按钮时，用扩展设置区的“找回悬浮按钮”。

原有酒馆助手全局变量的数据键保持为 `鲜虾鱼板面.data.v1`，会在其接口可用时继续读取。若没有酒馆助手接口，扩展可使用酒馆账号存储保存文风与草稿，但 C/U 和世界书操作需要酒馆助手。切换存储来源前，建议先在旧版本导出数据备份。

## V8.3 更新
- 聊天备份搜索改为搜索全部消息正文及发言人名字；不再按文件名、日期筛选。比如输入“花”，会匹配正文或发言人名字包含“花”的备份。
- 首次搜索按需读取备份，每次最多并行读取三个，显示读取进度和匹配数量。读取失败时明确提示结果不完整。再次搜索复用当前弹窗缓存；关闭弹窗清理缓存，日志不记录正文和关键词。
- 全选、搜索框、重新扫描对齐；列表勾选框与展开符号保持对齐，窄屏日期换行后展开符号仍垂直居中。
- 沿用 V8.2：只保留手动删除、立即清理两个入口；清理选项与位置插槽共用轻量界面设置，选择后立即保存；设置模板核对版本并禁用缓存。
- 保持独立弹窗、默认收起、展开显示最后一条消息、勾选删除及弹窗内确认；仅展示聊天备份。
- 未改动 C/U 编辑器；设置备份自动清理尚未接入。
- 已完成代码与模拟检查，尚未在用户酒馆实例实测。
