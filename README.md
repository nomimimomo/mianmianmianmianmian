# 鲜虾鱼板面 V10.6

基于 V10.1。覆盖扩展目录内同名文件后刷新酒馆。

四项功能可选默认或位置 1/2/3。默认沿用主面板，绑定共用账号设置，手机和电脑尺寸分别记录；空槽使用默认位置，需先在面板设置保存位置槽。

预设搜索详情可编辑正文。一键先保存当前预设（包括可见原生编辑框的修改），再写入新正文并保存，最后更新页面。失败保留编辑稿。预设写入酒馆服务器，同账号另一端刷新或重载预设后读取。


V10.6：预设搜索详情点击名称或正文直接编辑；命中统计右侧的保存按钮统一提交所有条目的草稿。切换条目可继续编辑后一起保存。


V10.6：空搜索显示当前预设条目；移除常驻已保存提示；DOCX 解析器已随 vendor 文件夹附带，PDF 改用酒馆原生解析入口。不需要额外安装后端。


V10.6：PDF 改为按逐页文字位置提取，保留换行、段落空隙和缩进，修正部首字符及文字块之间的额外空格。


V10.6：空搜索仅列标题；PDF 恢复逻辑段落，合并页面自动折行与跨页续文。已用用户提供的五页 PDF 验证列表、标题、英文与中文跨页拼接。手机实机未验证。
