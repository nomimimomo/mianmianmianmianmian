# 鲜虾鱼板面 V7.6

SillyTavern 第三方界面扩展。V7.6 基于 V7.5 更新，版本号在扩展信息、设置面板、启动日志和诊断日志中一致。

## 安装

1. 从 GitHub 安装时，把压缩包中 `鲜虾鱼板面` 文件夹内的六个文件放到仓库根目录，让 `manifest.json` 和 `index.js` 直接位于仓库首页；手动安装时，将整个文件夹放入当前用户的 SillyTavern 扩展目录 `data/<user-handle>/extensions/`。
2. 启用酒馆助手扩展（TavernHelper），它提供角色、User 和世界书读写接口。
3. 停用旧版鱼板面的酒馆助手脚本，刷新酒馆页面。请勿让两个版本同时运行，以免出现两个面板或覆盖同一份草稿。
4. 从扩展菜单、扩展设置区或悬浮按钮打开。手机找不到按钮时，用扩展设置区的“找回悬浮按钮”。

原有酒馆助手全局变量的数据键保持为 `鲜虾鱼板面.data.v1`，会在其接口可用时继续读取。若没有酒馆助手接口，扩展可使用酒馆账号存储保存文风与草稿，但 C/U 和世界书操作需要酒馆助手。切换存储来源前，建议先在旧版本导出数据备份。

## V7.6 本次修正

- 窄窗口识别同时参考浏览器窗口外宽，避免页面缩放后仍沿用电脑槽位的窄面板宽度。
- 窄窗口内保持面板左右各约 8% 留白，并维持 V7.4 的上下边界。

## V7.5 调整

- 在 601–800 像素的窄窗口中，面板左右边缘对齐外侧角色列附近，左右各留约 8% 宽度；旧电脑槽位的窄宽度不会让面板挤成一条。
- 宽电脑窗口的位置槽与手机端上下边界、底边拖动维持 V7.4 行为。

## V7.4 修正

- 手机面板上缘限制在酒馆顶栏下方，下缘限制在输入框上方；打开、切换位置槽、拖动及视口变化时均遵循边界。
- 手机拖动底边只改变下缘高度，上缘不跟着移动；可用空间变小时自动缩短，空间恢复后按已保存的高度显示。

## V7.3 修正

- 电脑浏览器收窄成竖长窗口时，也按顶栏与输入框之间的空间调整面板高度和上下位置，避免已保存位置使面板越界。
- 手机端原有的拖动底部调高度方式保持不变。

## V7.2 调整

- 电脑横屏时根据酒馆顶栏底边和输入框顶边确定面板的上下边界，并保留间距；面板高度随窗口和输入框大小变化。
- 已保存槽位继续控制左右位置及宽度，旧版本固定下移 24 像素的方式不再应用。
- 面板内的“设置”页和酒馆扩展设置栏维持 V7.1 的分工。

## V7.1 调整

- 面板顶部恢复“设置”页，位于“文风”右侧；此页只包含“面板位置与大小”，重新打开面板时保留当前页。
- 酒馆扩展设置栏保留数据存储、悬浮按钮和诊断日志，移除面板位置重复控件。
- 横屏下整个面板默认下移约 24 像素；升级时已保存的电脑端位置同步下移一次，之后拖动和保存仍按实际位置记录。

## V7.0 调整

- 酒馆扩展设置栏按确认的预览收紧间距，移除顶部介绍、重复打开按钮和长说明。
- 存储位置与选项同排；面板位置操作紧凑排列，窄栏时整齐换行。
- “显示悬浮按钮”开关在文字前，“找回悬浮按钮”在同一行右侧；日志按钮保持同排。

## V6.9 调整

- 将面面顶部的“设置”页移至酒馆扩展设置折叠栏，面面顶部只保留 C、U 和文风。
- 扩展设置提供数据存储、面板位置与大小、悬浮按钮、诊断日志的原有操作，并修正按钮在窄栏内竖排的问题。

## V6.8 修正

- Character 标签从酒馆头像对应的标签列表读取；旧草稿没有改动标签时，重新使用酒馆当前标签。
- 覆盖 Character 时同时写入角色卡的嵌入标签及酒馆列表标签，保存后校验标签映射。
- 世界书正文的回车、列表续行和缩进与人设卡使用同一按键处理；条目重绘后重新绑定且不重复绑定。

## V6.7 修正

- 修复中文及其他非英文标签名的未闭合提示，如 `<小简爸爸>`；同一文本框内多个未闭合标签仍逐个显示，补上闭合标签后消失。
- 修正 README 开头的版本沿革描述。

## V6.6 修正

- 窄面板的标点工具栏在鼠标悬停时可用普通滚轮横向移动，滚动条保持隐藏。
- C/U 内容区域只允许纵向滚动；长文本在可用宽度内换行，避免底部出现横向滚动条。
- 恢复未闭合标签提示：当前文本框的每个未闭合标签在主工具栏最前方显示对应闭合按钮；点击插入，双击隐藏该提示，切换文本框不混用。

## V6.5 修正

- 单篇文档导入先以文件名（去掉扩展名）精确匹配已有文风，之后才考虑文档内标题。
- `{{user}}` 和 `{{char}}` 保留在文风正文，其他成对 `{{…}}` 内容继续按原规则提取为备注。不会自动改动已有备注。

## V6.4 修正

- 导入文风选择弹窗将复选框与“全选 / 全不选”固定在同一行。
- 单篇 TXT、DOCX 或 PDF 导入时先用文档标题与现有文风匹配；命中后立即打开新旧版对比。
- 对比页按钮改为左侧“旧版”、右侧“新版”，与上方内容位置一致。
- 主面板工具栏补齐常用英文标点、中文引号和书名号等成对符号；点击成对符号，光标停在两者之间。

## 从 V6.2(1) 累计变化

- 加入 SillyTavern 扩展清单和独立设置入口，设置模板从 `settings.html` 加载。
- 使用扩展可访问的 `TavernHelper` 对象寻找原有写入接口，保留旧脚本环境中的函数查找路径。
- 手机悬浮按钮挂在 `body`，恢复位置时约束到可视视口；窗口尺寸变化后继续校正，保留原开关与大小设置。
- 文风库的全局正文替换移动到文风编辑页，点击“替换”再展开。未选条目时隐藏批量“全选”。
- 文风导入对比展示作者、标签、正文和备注，标出变化行；继续逐项选择新版、旧版或两版都保留。
- 保留 C/U 编辑、内置模板、快捷符号、世界书和已有面板布局，不改其数据结构。

## 验证范围

已检查 JavaScript 语法、扩展清单、界面选择器及压缩包结构。当前工作环境没有运行中的 SillyTavern 实例，安装后的导入与 C/U、世界书写入仍需在你的酒馆中验证。
