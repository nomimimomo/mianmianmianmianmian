# 鲜虾鱼板面 V10.22

用于酒馆 Character/User 资料编辑、文风管理、搜索、用户卡导入导出和备份清理。

本版优化中文搜索、搜索退出、高亮清理、手机小图标点击范围、编辑器监听和短暂通知。详细改动、参考来源、验证与未解决问题见《更新报告.md》。

更新：将压缩包内“鲜虾鱼板面”目录的文件覆盖到扩展目录。vendor 未改动，不必重复上传。保留原有数据，先在测试仓库使用。

正文选文编辑：选中文字后点小铅笔，绿色勾保存，红叉取消，回转箭头撤回。保存只替换原始消息对应片段；该消息状态栏可能随消息重新渲染。手机键盘覆盖能力取决于浏览器。

遇到问题：在设置导出诊断日志。版本、操作阶段、失败信息和键盘覆盖请求会记入日志。
