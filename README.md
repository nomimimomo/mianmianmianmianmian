# 鲜虾鱼板面 V9.6

将本包文件覆盖到原扩展目录并刷新酒馆。index.js、style.css、settings.css、settings.html 和 manifest.json 一起替换。
无需额外后端，也不需要 storage.js。

酒馆顶栏扩展设置可分别开关面面编辑器、文风管理、预设搜索、悬浮按钮和自动备份清理。面板位置、数据存储、备份规则与诊断日志统一放在鱼板面“设置”页。

预设搜索保持只读；关闭编辑器或文风管理保留已有数据。窗口顶部避开酒馆顶栏，底部避开输入框，左右各 2% 为外边界，边界内可自由缩窄、移动并锁定。

详细改动与开关对应关系见《更新报告.md》。

文风导入支持沿勾选栏拖动连选，电脑可用 Shift 连选。同名对比的“仅替换正文”保留旧名字、作者、标签和备注；“跳过此条”只处理当前条目。

正文完全相同的导入条目自动跳过；未匹配到旧文风时，确认新增或手动选择旧文风，仅替换正文。备份区域显示上次自动清理时间；关闭自动清理后，可点击“检查备份”查看待清理数量和大小。检查本身不会删除。
