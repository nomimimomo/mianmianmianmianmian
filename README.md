# 鲜虾鱼板面 V9.2

将本包文件覆盖到原扩展目录并刷新酒馆。index.js、style.css、settings.css、settings.html 和 manifest.json 一起替换。
无需额外后端，也不需要 storage.js。

预设编辑器“查看 / 编辑偏置预设”行右侧的 🔎 打开只读全文搜索，支持已启用/全部有效条目、同句合并预览和完整正文逐处定位。搜索不保存或修改预设，可一边调整原预设一边搜索。

主窗口、预设搜索窗与备份搜索窗统一避开酒馆顶栏和输入框，左右边距各不超过 8%。

清理设置选择后自动保存。“手动删除”打开聊天备份预览，“立即清理”执行现有期限规则。
详细改动和验证结果见《更新报告.md》。
